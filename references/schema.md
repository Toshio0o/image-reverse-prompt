# 反推元数据 schema

元数据分两层：通用层（所有图都填）加类型层（按主类型选一层填）。字段值写短语或短句，多个值用数组。不适用留空字符串或空数组，不编造。不确定的值后面加问号。

## 通用层 core（8 项）

- `image_type` 图像类型：真人摄影、产品渲染、插画、设计图、航拍等。
- `mood` 画面氛围：复古低饱和、明亮通透、冷峻高级、温暖生活气等，加一两词情绪定性。
- `composition` 构图取景：画幅（竖幅、横幅、方形）、机位（平视、仰拍、俯拍）、主体位置（居中、偏左、偏右）、留白方位。
- `lighting` 光线：光源方向、色温、软硬、时间感（正午、黄金时刻、阴天漫射）。
- `color` 色彩配色：主色调、配色关系（如橙帽是全身唯一亮色，与墙面同色系呼应）、饱和度高低。
- `texture` 成像质感：胶片颗粒、柔焦、锐利、景深浅深、噪点有无。
- `style` 风格滤镜：City Boy 街拍、美式复古、极简产品、现代建筑摄影等。
- `avoid` 防错提示：这张图生图时真正需要防的点，每条一句话，如避免裁掉鞋部、避免把遮脸改成露完整面部。

## 人像层 portrait（10 项）

源自 2026-11-24 人像拆解的 17 类细项中除通用层之外的部分，两张街拍实测验证。

- `subject` 主体人物：人数、性别、年龄感、人种或肤色特征。
- `build` 身形轮廓：高挑偏瘦、壮实、娇小等，加肩宽腿长等比例特征。
- `skin_tone` 肤色肤调：深棕、浅肤暖米色等。
- `action` 动作表情：全身动作（行走方向、站立、坐姿）、手部动作（哪只手做什么）。
- `micro_expression` 微表情情绪：眼神、嘴角、整体情绪（松弛、凌厉、沉静）。
- `hair_accessories` 发型妆容配饰：发型、帽子、眼镜、首饰，每件单独列。
- `outfit_structure` 服装结构贴合：按穿着顺序从外到内分层写，每层写版型与贴合（宽松、修身、堆褶）。
- `outfit_material` 服装材质：每件主要单品的材质观感（哑光挺括、厚实、轻薄防水）。
- `skin_detail` 皮肤光泽细节：真实皮肤阴影、光泽程度、是否保留瑕疵质感。
- `background` 场景背景：墙面、地面、环境元素，带材质与颜色。

配饰完整度单独注意：眼镜、手链、钥匙串、包袋、腰带这些小件逐件列，不合并，不省略。实测里曾漏过眼镜和手链，核验门专为此设。

## 风景层 landscape（6 项）

- `terrain` 地貌地形：山、海、森林、沙漠、草原、城市天际线等，加地形特征。
- `weather` 天气大气：晴、雾、雨、云、霾，能见度与空气感。
- `season_time` 时间季节：季节、日出日落、正午、蓝调时刻。
- `depth_layers` 景深层次：前景、中景、远景各是什么，层次如何过渡。
- `nature_detail` 自然元素细节：水面反光、植被形态、岩石纹理、雪线等。
- `human_element` 人为元素：道路、建筑点缀、人物比例参照，有则写，无则留空。

## 产品层 product（7 项）

- `product` 产品主体：品类、形态、数量、尺寸感。
- `material` 材质表面：金属、玻璃、皮革、塑料、哑光、高光，反光特性。
- `branding_text` 品牌标识文字：logo 与文字内容，逐字抄，抄不清写文字不清，无则留空。
- `arrangement` 摆放陈列：平铺、悬浮、手持、叠放、角度与朝向。
- `backdrop_props` 背景道具：纯色背景或场景背景，搭配的道具。
- `light_shadow` 光影倒影：产品光方向、倒影有无、阴影方向与软硬。
- `detail_closeup` 细节特写：接口、纹理、做工、刻度等近处才看清的细节。

## 建筑层 architecture（6 项）

- `building_style` 建筑类型风格：住宅、文化建筑、商业等，加风格流派（现代主义、解构主义、乡土）。
- `form` 结构形态：体量、层数、屋顶形式、立面节奏、对称与否。
- `material` 材料质感：混凝土、玻璃、木材、砖石、金属板，带表面质感。
- `openings` 开口细部：窗户比例与排列、门、阳台、装饰线条。
- `context` 环境关系：街道、周边建筑、植被、人物比例参照。
- `viewpoint` 视角透视：仰拍、平视、鸟瞰，透视变形程度。

## 室内层 interior（6 项）

- `space_type` 空间类型功能：客厅、卧室、咖啡馆、办公室等。
- `layout` 布局动线：家具分区、动线走向、空间开合。
- `furniture` 家具陈设：主要家具单品，带款式与摆放位置。
- `material_color` 材质配色：地面、墙面、家具材质与配色关系。
- `lighting_detail` 灯光：自然光入口、灯具类型、光影效果。
- `decor` 装饰细节：挂画、绿植、织物、小摆件。

## 食物层 food（6 项）

2026-11-24 两张图跑通后建层（披萨例 7、韩式热狗棒例 11）。

- `dish` 菜品主体：菜品名、形态、数量、切分状态（整只、切块、咬开）。
- `ingredients` 食材配料：主要食材与配料，带可见状态（融化、焦黄、切块、丝状）。
- `sauce` 酱料：酱料种类与淋法（波浪纹、点状、浸没），酱料碗有则写。
- `serving` 摆盘容器：盘、碗、砧板等，带材质、形状与摆放角度。
- `garnish_props` 点缀道具：散落的配菜、酱料碗、餐布、绿植等画面配角。
- `doneness` 熟度状态：融化、拉丝、焦边、蒸汽等表现熟度的细节。

## 动物层 animal（6 项）

2026-11-24 两张图跑通后建层（比格犬例 8、白兔例 12）。

- `animal` 动物主体：物种、品种、年龄感、姿态与朝向。
- `coat` 毛色毛发：毛色、花纹、毛发质感（蓬松、短毛、长毛）。
- `features` 特征细节：耳朵、眼睛、鼻子、尾巴等显著特征，带状态（竖起、垂下）。
- `expression_action` 表情动作：表情、动作、神态。
- `accessories` 配饰：项圈、花环、衣服等，无则留空。
- `habitat` 环境背景：栖息环境、地面、植被、虚化程度。

## 艺术绘画层 artwork（6 项）

- `medium` 媒介画种：油画、水彩、版画、数字绘画等。

- `subject_matter` 画面主体：花卉、人物、风景、静物等。

- `composition_color` 构图与色彩：构图方式、主色调、明暗对比。
- `details_motifs` 细节母题：昆虫、器物、签名等画面细节。

## JSON 示例骨架

```json
{
  "image": "图名或路径",
  "type": "portrait",
  "secondary_type": null,
  "core": {
    "image_type": "",
    "mood": "",
    "composition": "",
    "lighting": "",
    "color": "",
    "texture": "",
    "style": "",
    "avoid": []
  },
  "portrait": {
    "subject": "",
    "build": "",
    "skin_tone": "",
    "action": "",
    "micro_expression": "",
    "hair_accessories": [],
    "outfit_structure": [],
    "outfit_material": "",
    "skin_detail": "",
    "background": ""
  },
  "palette": []
}
```

`type` 取值：portrait、landscape、product、architecture、interior、food、animal、artwork、vehicle、illustration、poster、other。`secondary_type` 用于混合图的次类型，可为 null。类型层对象名与 `type` 值一致。`palette` 为色卡数组，每项含 hex、share、role，见脚本输出。
